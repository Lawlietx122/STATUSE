# Rep (Android, Kotlin + Compose)

Локальный симулятор соцсети с ИИ-персонажами. Сервера нет: все данные хранятся в SQLite (Room) на телефоне,
к моделям приложение ходит напрямую.

## Как открыть
1. Android Studio → **Open** → папка `android`.
2. Дождаться Gradle Sync. Если Studio предложит обновить AGP/Kotlin, можно соглашаться.
3. Run на эмуляторе или телефоне (minSdk 26).

## Первый запуск
1. Иконка робота → **Модели** → `+` → выбрать шаблон (OpenAI / OpenRouter / Anthropic / Ollama / LM Studio),
   вписать ключ и модель → **Тест**.
   Для Ollama/LM Studio на ПК: адрес `http://<IP ПК в Wi-Fi>:11434/v1` (или `:1234/v1`),
   а сам сервер должен слушать не только localhost (`OLLAMA_HOST=0.0.0.0`).
2. **Промпты** → заменить заглушки `TODO` своими.
3. `+` на главной → создать сценарий → вкладка «Персонажи» → добавить ИИ-персонажей.
4. Кнопка ⏩ (шаг времени) → +1 час и новые посты от персонажей.

## Где что
```
data/db/        Room: сценарии, персонажи, посты, комменты, чаты, сообщения, журнал токенов
data/ai/        AiProvider: OpenAiCompatibleProvider и AnthropicProvider; AiClient пишет расход токенов
data/settings/  Провайдеры и ключи (EncryptedSharedPreferences), пресеты адресов
data/prompts/   Шаблоны промптов с переменными {name}, редактируются в приложении
domain/         SimulationEngine: посты, комментарии, чат, сжатие переписки, шаг времени
ui/             Экраны Compose
```

## Промпты
У каждого вида запроса есть шаблоны `system` и `user`, а список переменных показан прямо на экране.
- **Комментарии NPC**: парсер ждёт по одному комментарию на строку в формате `handle: текст`.
  Если ник совпадает с персонажем сценария, комментарий привязывается к нему.
- **Чат**: история уходит в модель настоящими сообщениями user/assistant. Шаблон `user` можно оставить пустым.
  Когда несжатых сообщений больше 30, старые сворачиваются в summary (промпт «Сжатие»), последние 10 остаются как есть.

## Счётчик токенов
Каждый запрос пишется в таблицу `token_usage`: провайдер, модель, цель, вход/выход, длительность.
Числа берутся из `usage` в ответе API. Если сервер его не вернул (бывает у локальных моделей),
используется оценка «символы / 4», и запись помечается как «оценка».
Экран «Токены»: сегодня / 7 / 30 дней / всё, разбивка по моделям, последние запросы.
